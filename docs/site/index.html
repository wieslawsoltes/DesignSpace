Design visually.
Keep the engine yours.

An independent Blend-style XAML workspace built on Uno Platform. One C# application for desktop and browser, eight reusable libraries.

Development preview, not full or pixel-exact Microsoft Blend parity. Real authoring workflows are implemented; the compatibility matrix distinguishes them from preserved-only markup.

Start designing

Use Assets to add controls or the toolstrip to draw shapes. Properties edits the selection. Group Canvas siblings, align, distribute, duplicate and reorder with undo/redo. Use F to fit, H to pan, and Control + wheel to zoom around the pointer. Resizable panes can be hidden, restored or floated inside the app.

Layout, images and templates

Layout supports intrinsic Auto and weighted Star Grid tracks, spacing and sizing constraints. Import image copies as embedded raster data. Use Templates to author inert ControlTemplate resources with scoped styles, TemplateBinding and ContentPresenter previews.

Source and recovery

Switch to Split or XAML and apply source with Control + Enter. Invalid drafts remain editable; stale drafts cannot silently overwrite newer designs. Save native .designspace files for durable copies. Local recovery is not a backup.

Work across documents

New and Open add tabs. Each document retains its own undo/redo, object selection, source and supported panel drafts, timeline position and viewport. Drag tabs to reorder, or right-click to pin and close other unpinned documents. Project lists the same open set. Overflow arrows keep tabs and commands reachable.

Save all writes changed native documents and returns to the original tab. Closing unsaved work offers Save, Discard and Cancel. Save workspace writes all documents and unapplied drafts into one .designspace-workspace file. Invalid source is kept as text, not applied. Local recovery restores the open set; undo history survives switching but is not serialized.

Use the split-orientation button for horizontal or vertical source/design views. Mode, splitter ratio and viewport are document-local. F6 switches Design and Animation workspace profiles. This is one active designer surface, not a full solution compiler or native multi-window implementation. Workspace guide and integration contracts →

Draw and edit vector paths

Pen (P): click to place corners, drag to create curve tangents, and click the first point to close. Enter finishes an open contour; Escape discards the draft. Pencil (Y) creates a simplified, editable freehand outline. Each completed path is one undoable edit.

Direct Selection (A): Shift-click anchors or Shift-drag a point marquee. Drag selected anchors together; Control + A selects all anchors in the current Path and Control + Shift + A clears them. Arrows nudge in artboard units, Shift increases the step, and Delete removes the selected points. Escape cancels a live point drag or marquee. Tangent handles remain individually editable; Alt breaks the link between neighboring cubic handles. With Pen, click an existing anchor to remove it or an edge to insert a point without changing its Bezier shape.

Open Paths to align or distribute selected points, convert shapes, change line/curve segments, open/close figures, and choose EvenOdd or Nonzero fill. Combine Canvas siblings using Unite, Intersect, Subtract, Exclude, two-shape Divide, or a compound path. Make clipping path uses the top selected vector as the lower object's clip. Undo restores the original shapes.

Combined results are vector data, not screenshots. Locked or animation/state-linked destructive operands are protected. Point selection is scoped to one Path and is transient; geometry edits survive undo and recovery. Multi-object point selection, persistent tangent modes, pressure brushes and complete geometry-group semantics remain unfinished.

Stroke appearance and outlines

Select a vector shape and open Stroke to edit width, independent start/end caps, dash caps, joins, miter limit, dash array and offset. The preview is a draft; Apply stroke commits its changes together, and Reload discards it. Mixed values are retained unless explicitly changed. Stale drafts cannot overwrite a newer document revision.

Dash lengths and offsets use multiples of width. The Dot preset uses zero-length painted entries with round caps. Visible gaps are also gaps in hit testing; empty clicks do not reselect the shape through its bounding box. Width zero removes the stroke rather than creating a hairline.

Convert stroke to path turns supported solid-color strokes into editable filled vector contours while retaining the object identity and undo. Filled, locked, state-linked and unresolved brush/style-dependent objects are protected. Stroke semantics, API ownership and limits →

Gradient brushes and opacity masks

Open Brush to author solid, linear or radial brushes. Edit or drag gradient stops, set independent radial radii and focus, choose mapping and spread, and apply relative/absolute transforms. Apply commits one undoable edit; invalid drafts stay isolated and follow document tabs.

OpacityMask fades the element and its subtree using brush alpha, not color brightness. Native gradient shaders and scoped resources are shared by fills, strokes, text and borders. This is sRGB interpolation, not a complete WPF brush runtime.

Storyboard timing

Select an object and numeric property, move the playhead and add a keyframe. Record values at the current time, drag diamonds to retime keys and choose easing. The timeline ruler stays in the original keyframe interval.

Choose Timing to set duration, start delay, speed, auto-reverse, repetition by count or duration, infinite repetition and HoldEnd/Stop behavior. Use Apply timing to commit. Enable Scale keyframes when changing duration to retime keys proportionally; shortening without scaling rejects keys outside the new interval instead of deleting them.

Playback uses elapsed time and the timing options. Scrubbing edits local keyframe time directly, even when playback has a delay or repeats. Stop fill behavior restores underlying values when playback finishes.

Groups and generated transitions

States now lists named groups, each with one active state. Select a group header to choose where new states are created. Open Transitions to add, rename or delete groups and edit generated transition rules. State renaming updates rule selectors; deletion and its dependent rules are undoable.

Use * in From or To for any state. Exact pairs take precedence, then destination-only, source-only and default rules. Set duration in seconds and choose linear or cubic easing. Enable Animate in States to preview position, size, opacity and solid-color transitions. An interrupted transition starts from its current displayed value. Group Base resets only that group; the top Base resets all groups.

Independent groups can preview disjoint properties together. Conflicting properties are rejected. Auto sizes and other non-interpolatable values switch at completion. Active preview does not write animation frames into the document or undo history. The editor rejects stale drafts until reloaded. Native files and supported XAML retain group membership and transition rules; active preview state is transient.

Record visual-state overrides

In States, select a state and enable Record state. Edits in Properties now change that state's overrides without changing the base object. The inspector displays the editing context and effective values. Focus a property and use Reset property to remove its override; undo restores it. Select Base to leave state recording.

Solid colors and brush resource references can be recorded. Inline gradient authoring remains a base operation and is blocked during state recording. Generated transitions are supported, but explicit transition storyboards, automatic triggers and a complete template VSM runtime are not.

Reusable libraries and performance

Core, Engine, Animation and Xaml contain portable document behavior. Rendering.Skia draws into a caller-owned canvas with HarfBuzz shaping, shared styled measurement and bounded glyph/line caches. Repainting warm paragraphs avoids reshaping and rewrapping. Docking.Uno and Controls.Uno expose individual controls; Workbench.Uno composes them around host storage and clipboard services.

The status bar measures CPU drawing submission, not GPU completion or frame presentation. Browser CI uses software-backed WebGL. The implementation shares Uno's GPU-capable Skia host; it is not a separate WebGPU compute renderer.

Compatibility and verification

Imported XAML is data, not executable code. Unsupported nested timelines, per-child clocks and arbitrary behaviors remain preserved markup, not editable simulations. Advanced vector editing, rich bidi/fallback typography, multi-document project compilation and native multi-window docking remain unfinished.

CI verifies portable behavior, trimming, image pixels, templates, typography/vector caches, path and clip pixels, three desktop builds and actual browser pointer/keyboard workflows. Pages verifies its public commit identity. Release packaging checks all eight packages and both Uno target frameworks; it does not automatically publish to NuGet.org.
