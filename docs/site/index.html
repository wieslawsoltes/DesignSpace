An independent Blend-style XAML workspace built on Uno Platform. One C# application for desktop and browser, eight reusable libraries.

Development preview. The editor supports real document editing, but does not yet provide full or pixel-exact Microsoft Blend compatibility.

Start designing

Use Assets to add controls or the toolstrip to draw shapes. Select, move and resize objects on the artboard. Properties edits their values. Group Canvas siblings, align, duplicate and reorder them with undo/redo. Use F to fit, H to pan, and Control + wheel to zoom around the pointer.

Source and persistence

Switch to Split or XAML and apply edits with Control + Enter. Invalid drafts are retained; stale revisions cannot overwrite newer design changes. Save native .designspace files for durable copies. Local recovery is not a backup. File also exports XAML and PNG.

Animation and states

Select an object and numeric property, move the playhead and add a keyframe. Enable recording to author property values at the current time. Drag diamonds to retime keys, change easing, scrub or play. States can capture selected property values and preview overlays.

Reusable libraries

Core, Engine, Animation and Xaml provide portable document behavior. Rendering.Skia draws into a caller-owned canvas. Docking.Uno and Controls.Uno expose the individual panels. Workbench.Uno composes the workspace around host-provided storage and clipboard services.

Compatibility and verification

Imported XAML is data, not executable code. Retaining unsupported markup does not mean its behavior is implemented. Read the compatibility matrix before importing production projects.
